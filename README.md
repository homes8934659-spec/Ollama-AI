# Ollama AI

**An AI-powered coding and research assistant for Windows.**

> ⚠️ **Windows 10/11 only**

## Requirements

- Windows 10 or Windows 11
- [Ollama](https://ollama.com/download/windows) installed
- An Ollama model installed

## Features

- 💬 AI Chat
- 🤖 Agentic research mode
- 💻 AI code generation
- ✏️ Surgical code editing
- 📁 File explorer
- 🔍 Code analysis
- 🛠️ Automatic syntax checking and repair

## Installation

1. Install Ollama.
2. Download **Ollama AI Setup.exe** from the latest release.
3. Run the installer.
4. Launch **Ollama AI**.
